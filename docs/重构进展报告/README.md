# 重构进展报告

本文件夹存放 v2.1 全栈重构（Streamlit → FastAPI + React）的过程性报告。

## 制度

- 每完成**一部分任务**或**一个阶段**，在此文件夹保存一份 Markdown 报告
- 报告内容至少包括：
  1. **完成了什么**——交付物清单（文件、端点、功能），附验证结果
  2. **偏差**——与计划（`docs/v2.0-全栈重构方案.md`）不一致的地方及原因
  3. **需要注意的事项**——发现的坑、遗留问题、给后续阶段的提醒
- 命名规范：`DayNN-YYYY-MM-DD-主题.md`（DayNN 为重构第 N 天，与方案第六部分的 15 天节奏对应）
- 本要求已写入项目根 `AGENTS.md`，对人和 AI 协作者同样生效

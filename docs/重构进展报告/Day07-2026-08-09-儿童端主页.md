## 2. 偏差

- 主页只放两个入口（聊天/星球），未加共创故事第三入口——按需求严格二选一；共创仍从星球页卫星卡进入。
- `data-time` 渐变 CSS 在 ChildHome.css 与 MyPlanet.css 各存一份（4 条规则）：抽公共类会牵动两页根节点结构，收益不抵耦合，暂不抽。

## 3. 需要注意的事项

- **首站变更影响演示动线**：`demo_kid` 登录后现在落在 `/home` 而非 `/chat`，录制演示视频/截图时注意多一步点击。
- `LandingGate` 与 `Landing.goByRole` 两处跳转都改成了 `/home`，后续若调整首站需同步这两处 + ChildHome 的家长 redirect。
- 主页问候用户名来自 localStorage `anxin_user`，与星球页问候口径一致。
- 真机观感（两张卡的 320px 表现、夜间色温）建议浏览器过目。

## 一、完成了什么

### 1.1 设计系统定稿：`docs/DESIGN-anxin.md`

对照 `DESIGN-lovable.md` 与 `DESIGN-shopify.md` 后确定的融合方案：

- **Lovable 给材质**：奶油 `#f7f4ed` + 炭黑 + 透明度灰阶 + 暖边框（与现有 Demo token 连续）
- **Shopify 给结构**：双轨制——儿童端（粉彩 + 宽松 + 圆润黑体）/ 家长端（石板青 + 收紧 + Inter），同 DNA 分轨道
- **自加两层**：粉彩"活的色彩层"（与 risk 语义色同源）+ 动效语言（spring 生长感，无机械滑动）
- **产品负责人三项决策**：① 双轨策略 ✓；② 安全引擎页深色例外（`.dark-safety` 作用域）✓；③ 标题字用圆润黑体，不用活泼字体 ✓

### 1.2 前端儿童端（29 个文件，全部在 `frontend/`）

- **脚手架**：Vite 5 + React 18.3 + react-router-dom 6 + framer-motion 11 + @fontsource/nunito；dev 代理 `/api`；build 输出 `dist`（后端直接托管）
- **样式**：`tokens.css`（base）/ `track-child.css` / `track-parent.css`（含 `.dark-safety`）/ `global.css`——严格照抄 DESIGN-anxin.md，零自造色值
- **Landing.jsx**：品牌区 + 登录/注册；注册含角色/年龄档选择卡、**监护人同意勾选（不勾禁用提交 + 提示，双保险）**、儿童角色可填家长用户名关联；登录按 role 分流
- **ChildrenChat.jsx（核心）**：
  - SSE 手工解析（fetch POST + ReadableStream，`\n\n` 分块——EventSource 不支持 POST）
  - **等待期 UI**（应对 5-15s 回放时序）：呼吸盾牌动画 + 轮换儿童友好提示，不显示技术步骤名
  - 打字机渲染 token；done 后渲染 🛡️"已安全检查"徽章（**不给孩子看风险等级**）+ 推荐卡片 + 每日挑战卡片
  - **合规三件套**：AI 身份徽章常驻、注册监护人同意、`useUsageTimer` 累计 120 分钟温暖提醒（可关闭不强制）
  - **语音**：VoiceButton（webkitSpeechRecognition 填入输入框）+ TTS 开关（speechSynthesis 播报回复），不支持浏览器自动隐藏
  - 危机模板回复用新芽绿温和边框呈现，无任何惊恐化 UI；网络失败换温和文案
- **占位页**：MyPlanet（Day 03 正式做）、ParentStub（Day 04 正式做）；路由守卫无 token 跳 `/`

## 三、需要注意的事项（给后续阶段）

1. **端口纪律**：本机 8000/5173/8001 被其他项目占用——本项目统一 **后端 8765**；vite dev 若 5173 被占会自动顺延，注意看终端输出的实际端口
2. **SSE 回放时序是前端设计的硬约束**：等待期 UI 不是装饰，是必需品（5-15s 无事件）。Day 03 的星球页如接 SSE 也要沿用同一模式
3. **儿童端的信息纪律**：不显示风险等级/决策链/技术步骤名——这些全归家长端。`done` 事件里的 `risk_level`/`decision_record` 前端已接收但刻意不渲染，家长端阶段会用到
4. **生产模式单进程**：`npm run build` 后 uvicorn 直接托管 dist（SPA 回退已配好）——这就是部署形态，Day 05 部署时无需再动
5. **子代理被手动中断过一次后恢复**：未造成文件损坏，交付完整

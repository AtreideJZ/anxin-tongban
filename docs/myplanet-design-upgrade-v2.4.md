# 「我的小星球」设计升级方案 v2.4（评审 + 重构版）

> 基于 v2.3（`docs/myplanet-design-upgrade.md`）的评审结论。
> 评审参照 Kimi Design Principles（Semantic Hierarchy / Purposeful Motion / Platform Fit）与
> `frontend/src/pages/MyPlanet.jsx` 当前实现。
> **总判断：v2.3 方向正确、工程纪律好，主要风险是"加法过多"——五个新机制同时上线会稀释视觉主角。v2.4 保留其骨架，做收敛与合并。**

---

## 一、对 v2.3 的评审

### 1.1 值得保留的（评审通过）

| 项 | 评价 |
|---|---|
| 类型语系统一（树 ⇄ 卡片 ⇄ 筛选器同色） | ✅ 最强的改动，直接解决"树是孤立装饰"的问题 |
| 动效纪律（纯 CSS 循环动画、`prefers-reduced-motion`） | ✅ 与 Purposeful Motion 及性能要求一致 |
| 空状态引导（占位卫星可点击打开表单） | ✅ 把"空"变成了入口，符合 CRUD 完整性 |
| 分阶段实施 P0/P1/P2 | ✅ 节奏合理 |
| 表单 modal 化 + backdrop blur | ✅ 避免打断星球氛围 |

### 1.2 需要修改的（按严重程度排序）

**P-A. 信息层级竞争：首屏 emphasis 点过多**
v2.3 的阅读动线是 Hero → 树 → 记忆轨道 → 胶囊花园 → 条目区，共 5 个强调区块。
Semantic Hierarchy 原则要求"一个局部区域避免多个竞争强调点"。儿童页面的视觉主角应该**只有生命树一个**。
- Hero 大气层带 + 吉祥物 + 大标题 + 天气 + 生态，本身已经是一个完整 emphasis，再放树就形成"双主角"。
- 「记忆轨道」与「类型筛选 chips」是两个功能重复的导航机制（都是"按类型找到记忆"）。保留一个即可。

**P-B. 动效总量超标**
v2.3 同时引入：滚动入场 stagger + 5 种天气循环动画 + 新增记忆粒子 + 双向 hover 发光联动 + 卡片 popIn。
对情感页可以放宽，但仍需"动效预算"：**任一视口内最多 1 个环境循环动画 + 1 个交互触发动效**。
另外 `animate={{ filter: "drop-shadow(...)" }}` 会触发 paint，不走 GPU 合成，应改为 `transform: scale()` + 预渲染的 glow 层 opacity 切换。

**P-C. 双向 hover 联动在移动端无效且不可发现**
Platform Fit 原则：web hover 在移动端必须有 pressed/显式控件等价。且 hover 联动是隐藏功能——孩子不会发现"摸卡片树会亮"。
改为**点击驱动**：点击树上元素 = 筛选该类型（与 chips 合并），点击即发现。

**P-D. 分步表单对低龄档过重**
3 步 modal 对 5-7 岁守护模式孩子认知负担偏高。分龄：5-7 一步表单（类型大图标 + 一个输入框）；8+ 保留当前单表单即可，分步收益不大。

**P-E. 验收标准不可测**
"3 秒内感知这是我的星球"无法操作化。改为可检查项（见第八节）。

### 1.3 v2.3 没覆盖到的新机会

- **回访动机缺失**：星球页目前是"仓库"，孩子没有理由每天回来。`core/daily_challenges.py` 已存在但未在星球页露脸。
- **时间维度缺失**：条目只按类型分组。孩子的记忆天然是时间的（"这一周"），类型分组是成人视角。
- **昼夜/时段氛围**：星球页是唯一适合"现在是什么时候"的页面，早/晚打开氛围不同是低成本高情感回报的改动。

---

## 二、v2.4 升级目标（修订）

1. 生命树是页面**唯一**视觉主角，其余区块降一级。
2. 导航机制合并为一个「星球罗盘」（类型筛选 + 树联动 + 最近记忆，三合一）。
3. 动效实行预算制，点击驱动替代 hover 联动。
4. 增加回访动机（今日挑战）与时间维度（本周视图）。
5. 分龄交互深度。

---

## 三、布局重构（动线收敛）

```
[轻 Hero: 一句话问候 + 今日小挑战胶囊条]      ← 降级：无大气层带、无吉祥物
          ↓
[生命树 GrowthTree 居中（唯一主角，含天气环境）]
          ↓
[星球罗盘 PlanetCompass: 4 枚类型卫星]
   · 常显（无内容类型显示虚线占位）
   · 点击 = 筛选条目区 + 树对应元素点亮
          ↓
[条目区: 「本周」时间条 / 类型分组 双视图切换]
          ↓
[时间胶囊花园（横向架，位置下调）]
          ↓
[共创故事入口（故事卫星卡片）]
```

相对 v2.3 的变化：
- 删除独立「大气层 Hero」与「记忆轨道」两个组件，功能分别并入问候条和罗盘。
- 胶囊花园从动线第 3 位移到条目区之后——它是"未来的惊喜"，不应打断"现在的记忆"浏览。
- 共创入口位置不变（故事分组附近），视觉沿用 v2.3 §5.5。

### 3.1 轻 Hero（替代 v2.3 §3.1）

一行问候 + 一个可点击的「今日小挑战」胶囊条：

```jsx
<header className="planet-hero">
  <h1 className="planet-hero__greeting">{greeting}, {nickname}的小星球</h1>
  <Link to="/chat" className="daily-challenge-pill">
    🌞 今天的小挑战：{challenge.text}
  </Link>
</header>
```

- `greeting` 按时段：早上好/下午好/晚上好（同时驱动 §3.3 昼夜氛围）。
- 挑战文案来自后端每日挑战接口；点击跳回聊天页完成挑战——**这是回访动机的闭环**。
- 不做大气层渐变带与吉祥物（P-A）：树的天气氛围 already 承担了这个角色，重复会分散注意。

### 3.2 星球罗盘（合并 v2.3 §5.2 轨道 + §5.4 chips + §6.1 联动）

```jsx
function PlanetCompass({ counts, activeType, onSelect }) {
  return (
    <nav className="planet-compass" aria-label="星球罗盘">
      {GROUPS.map((g) => (
        <button
          key={g.type}
          className={`compass-satellite ${activeType === g.type ? "is-on" : ""} ${counts[g.type] === 0 ? "is-empty" : ""}`}
          style={{ "--satellite-color": g.dot }}
          onClick={() => onSelect(activeType === g.type ? null : g.type)}
          aria-pressed={activeType === g.type}
        >
          <span className="compass-satellite__icon">{TYPE_META[g.type].icon}</span>
          <span className="compass-satellite__label">{TYPE_META[g.type].label}</span>
          <span className="compass-satellite__count">{counts[g.type] || ""}</span>
        </button>
      ))}
    </nav>
  );
}
```

- 选中态：卫星背景变为类型色 15% 填充 + 树上对应元素 scale(1.15) + 预渲染 glow 层淡入（不用 filter 动画，P-B）。
- 再点一次取消筛选（回到全部）。空类型显示虚线描边，点击直接打开对应类型的种下表单（沿用 v2.3 空状态思路）。
- 移动端：4 枚横排即可（每枚 ≥64×64px，满足 44px 触摸目标），不需要横向滚动。
- 树内元素也可点击，点击效果 = 点对应卫星（`aria` 上树元素是装饰，罗盘才是导航控件）。

### 3.3 条目区双视图

分组标题旁一个轻量分段切换（segmented control）：

- **「本周」视图（默认）**：最近 7 天条目按天分组的横向时间条，每天一条竖列，卡片紧凑排列。强化"这一周我经历了这些"的故事感；超过 7 天的收到「更早」折叠区。
- **「种类」视图**：即当前四类分组（筛选联动罗盘）。

低龄档（5-7）默认只显示「本周」，不暴露切换（认知减负）；8+ 显示切换。

### 3.4 昼夜与时段氛围（新增）

- 依据本地时间给页面根节点加 `data-time="morning|afternoon|evening|night"`。
- CSS 仅调整全局背景渐变与树的氛围色温（奶油色 → 暖橙 → 淡紫蓝），**不加新动画**。
- 成本约 30 行 CSS，情感回报高："晚上的小星球"是孩子会记住的时刻。

## 四、动效预算（修订 v2.3 §4）

| 动效 | 类型 | 频率 | 保留/调整 |
|---|---|---|---|
| 天气环境循环动画 | 环境 | 持续 | ✅ 保留，但**同一时刻只激活当前天气那一种**（本来就是），雨滴/涟漪用 CSS keyframes |
| 滚动入场 whileInView | 入场 | 每区 1 次 | ✅ 保留，spring 改 `duration: 0.5, bounce: 0.15`（bounce 克制） |
| 罗盘选中联动 | 交互 | 高频 | ⚠️ 改 transform + opacity，禁用 filter drop-shadow 动画 |
| 新增记忆粒子 | 反馈 | 低频 | ✅ 保留（罕见事件可以 delight） |
| hover 卡片 ↔ 树发光 | 交互 | 高频 | ❌ 删除（P-C），点击筛选已覆盖 |
| 卡片 hover 托起 | 交互 | 高频 | ⚠️ 仅在 `@media (hover: hover) and (pointer: fine)` 下启用，移动端用 `:active` scale(0.98) |

入场数值统一：`opacity 0 + translateY(16px) → 0`，stagger 50ms，ease-out `cubic-bezier(0.23, 1, 0.32, 1)`。

## 五、表单与反馈（修订 v2.3 §5.6 / §6）

- **5-7 岁**：点击「种下」→ 全屏底部面板，只有两个元素：4 个大类型图标（≥72px）+ 一个输入框。心情/标签不暴露。
- **8+ 岁**：沿用现有单表单 modal 化（backdrop blur + 居中），不分步——字段只有 4 个，分步反而多一次点击。
- 种下成功反馈保留 v2.3「种下了 ✨」+ 树粒子，补一个：**新卡片滚动进入视野**（`scrollIntoView({ behavior: "smooth" })`），让孩子看到"它落在星球上了"。
- 删除确认、胶囊破壳沿用 v2.3 §6.2。

## 七、实施优先级（重排）

| 阶段 | 内容 | 文件 | 理由 |
|---|---|---|---|
| P0 | 类型语系统一、星球罗盘（含树点击联动）、轻 Hero + 今日挑战条、入场动效 | `MyPlanet.jsx/css`、`GrowthTree.jsx`、新 `PlanetCompass.jsx` | 一次解决"主角不明 + 导航重复 + 回访动机"三个核心问题 |
| P1 | 本周视图、昼夜氛围、胶囊花园下移与横向架、表单分龄 | `MyPlanet.jsx`、`TimeCapsule.jsx/css` | 体验深化，不动信息架构 |

预计影响文件与 v2.3 相同量级，但组件净增只有 `PlanetCompass` 一个（删除轨道与大气层 Hero）。

## 八、验收要点（可操作化）

- [ ] 首屏（未滚动）内只有生命树一个大面积彩色元素；Hero 为纯文本 + 一个胶囊条。
- [ ] 点击罗盘卫星后：条目区只剩该类型、树上对应元素放大、再次点击恢复——三步内可验证。
- [ ] 任一时刻页面上运行的 CSS 循环动画 ≤ 1 组（DevTools Animations 面板可查）。
- [ ] 打开页面时段分别设为 9:00 / 21:00，背景色温明显不同。
- [ ] `prefers-reduced-motion: reduce` 下：无位移动画，罗盘切换、筛选、表单全部可用。
- [ ] 320px 宽度：罗盘 4 枚横排不换行不溢出；触摸目标 ≥44px。
- [ ] 儿童端全页面不出现风险等级、决策链、技术步骤名（既有纪律回归）。
- [ ] 新增条目成功后，新卡片自动滚入视野且树中心播放一次粒子。

---

## 九、明确不做的（防止范围蔓延）

- 不做大气层 Hero 与吉祥物插画（与树天气氛围重复）。
- 不做 hover 双向联动（移动端无效、不可发现）。
- 不做 3 步分步表单（字段太少，收益不抵成本）。
- 不给星球加"等级/积分/连续打卡天数"等游戏化数字——与产品"反焦虑、反成瘾"基调冲突。
- 不做 3D / Canvas 粒子系统——SVG + CSS 足够，且低端安卓设备要保 60fps。
